# 15 - Invoices Service

Source: `apps/api/src/modules/invoices/invoices.service.ts`

## Why This File Matters

Invoices are downstream of payroll. This service shows how one domain module consumes another module's records and creates a financial artifact. It also models status changes like issue and mark paid.

## Line-By-Line Reading Notes

Lines 1-4 import Nest exceptions, request context, audit, and Prisma.

Lines 6-11 define the injectable service and dependencies.

Lines 13-21 implement `list()`. It optionally filters invoices by organization and includes line items plus payroll cycle data.

Lines 23-96 implement `createFromPayroll()`.

Lines 24-28 load the payroll cycle, its items, and any existing invoice.

Lines 30-32 prevent duplicate invoice generation for the same cycle.

Lines 34-36 require payroll approval before invoice generation. This is an important cross-domain invariant.

Line 38 chooses the invoice currency from the first payroll item, defaulting to USD if there are no items.

Lines 39-41 reject mixed-currency cycles. Multi-currency invoices need explicit FX handling, not accidental addition.

Lines 43-45 calculate subtotal, service fee, and total. The service fee is currently a fixed 7%.

Line 47 starts a transaction.

Lines 48-70 create the invoice and nested line items. The line items include payroll items plus one platform service fee row.

Line 54 creates a human-readable invoice number from the current year and payroll cycle id suffix.

Lines 72-85 write an audit log for invoice generation.

Line 87 returns the created invoice.

Lines 98-120 implement `issue()`. It updates status to `ISSUED`, sets `issuedAt`, sets `dueAt` to 30 days from now, and audits the change.

Lines 122-141 implement `markPaid()`. It updates status to `PAID`, sets `paidAt`, and audits the change.

## Codebase Connections

- `PayrollService.advance()` must move a cycle to approved before this service can generate an invoice.
- `OperationsDashboard` exposes invoice generation, issue, and paid actions.
- The Prisma schema enforces one invoice per payroll cycle.
